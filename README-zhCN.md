# Łacinka

[English](./README.md)

Łacinka 是一个桌面转写工具，基于 Electron + C++ 原生转换核心。
它可以通过应用界面或标准输入接收文本，并转换为多种语言的拉丁字母写法。

## 功能

- 8 种转写模式（希腊语、塞克语、朝鲜语、白罗斯语、乌克兰语、拉丁语、俄语）
- 无边框 Electron 窗口，自带标题栏（最小化 / 最大化 / 关闭）
- 输入面板带实时字数统计与长度进度条
- 按当前模式切换的「插入示例」按钮——不同模式插入不同的示例文本
- 交换输入输出、复制输出、导出 `.txt` / `.json`
- 白天/黑夜主题切换与窗口置顶
- 中文/英文界面切换（i18n）
- 状态栏显示当前状态与上次运行时间；错误横幅与轻提示（toast）
- 键盘快捷键：`Ctrl+Enter` 触发转写，`Esc` 关闭下载菜单
- 桌面端复用同一套原生 CLI 转写器（`transform_cli`）

## 工作方式

前端 Electron 负责界面交互，真正的转写逻辑由 `transform_cli` 这个 C++ 程序完成。
桌面应用是原生转换器的外壳。

## 运行

启动 `Lacinka.exe`。

## 项目结构

- `main.js` - Electron 主进程（窗口管理、IPC、启动 `transform_cli`）
- `electron-start.js` - 本地开发启动器
- `frontend/` - 渲染进程界面
  - `index.html`、`style.css`、`renderer.js` - 界面与交互逻辑
  - `preload.js` - 上下文桥接（窗口控制 + 转写）
  - `i18n/` - 中英文语言字典
- `core/common/Common.js` - 共享示例文本与配置（字数限制、提示时长）
- `core/transform/` - 各语言转写实现（C++）
- `tools/transform_cli.cpp` - 原生命令行入口
- `launcher/` - 构建脚本
- `assets/icons/` - 应用图标

## 备注

- 字数超过 1000 字符时计数显示警告，超过 5000 字符时标记为超限
- 「插入示例」按钮会按当前模式插入对应的示例文本
- 导出格式：纯文本 `.txt` 与 `.json`（JSON 文件包含模式、输入与输出）
