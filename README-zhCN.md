# Łacinka

[English](./README.md)

Łacinka 是一个桌面转写工具，基于 Electron + C++ 原生转换核心。
它可以通过应用界面或标准输入接收文本，并转换为多种语言的拉丁字母写法。

## 功能

- 转拉丁字母
- Electron 界面，支持示例文本、字数统计、交换输入输出、复制、下载、主题切换、置顶
- 桌面端复用同一套原生 CLI 转写器

## 转写模式

| 模式 | 源语言 | 目标转写 |
| --- | --- | --- |
| 0 | 希腊语 | 拉丁字母 |
| 1 | 塞克语 | 拉丁字母 |
| 2 | 朝鲜语 | 罗马音 |
| 3 | 白罗斯语 | 拉丁字母-老版Łacinka |
| 4 | 白罗斯语 | 拉丁字母-新版2007 |
| 5 | 乌克兰语 | 拉丁字母 |
| 6 | 拉丁语 | 古拉丁字母 |

## 工作方式

前端 Electron 负责界面交互，真正的转写逻辑由 `transform_cli` 这个 C++ 程序完成。
桌面应用是原生转换器的外壳。

## 运行

启动 `Lacinka.exe`。

## 项目结构

- `main.js` - Electron 主进程
- `electron-start.js` - 本地开发启动器
- `frontend/` - 渲染进程界面
- `core/transform/` - 各语言转写实现
- `tools/transform_cli.cpp` - 原生命令行入口
- `launcher/` - 构建脚本
- `assets/icons/` - 应用图标

## 备注

- 界面支持示例文本，以及导出 `.txt` / `.json`
- 在桌面应用中可用 `Ctrl+Enter` 触发转写
